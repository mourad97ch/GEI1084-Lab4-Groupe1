Shift (S1-S11) - Groupe 1 - Hatem
Branche : feature/shift. Outils : Vivado/XSim 2022.2, xc7z007sclg225-1, VHDL-2008.

Ce qui a change :
- phase4/src/shifter.vhd : shifter combinatoire, LSL et LSR logique.
  shamt = Instr(11:7), sh = Instr(6:5), bit4 = Instr(4).
  ASR, ROR et decalage par registre : hors portee, operande transmis tel quel.
- phase4/src/datapath.vhd : RD2 -> shifter -> entree d0 du mux ALUSrc.
  ExtImm (d1) n'est jamais decale. WriteData = RD2 non decale.
  Interface du datapath inchangee (aucun port ajoute ou retire).
- LSL #0 = identite : les instructions registre du Lab 4 (bits 11:4 = 0)
  gardent le meme comportement.
- Cas limite ARM (reserve de Haroun, PR #6) : LSR avec imm5 = 0 encode LSR #32,
  resultat 0. Corrige par Mohamed Aziz au commit 647cab6 (integration), test S11.

Tests :

- Attendus generes par phase4/scripts/gen_shift_tests.py, un modele ARM ecrit
  a partir de la specification (independant du VHDL).
- Banc : phase4/sim/tb_shift_catalog.vhd (generics PROGRAM_FILE / EXPECTED_FILE / TEST_ID).
